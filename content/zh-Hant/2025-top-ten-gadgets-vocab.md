## 黑膠 — ㄏㄟ ㄐㄧㄠ · C2

**意思 / meaning:** vinyl (records). Short for 黑膠唱片 — "black-rubber record".
**拆解 / breakdown:** 黑 "black" + 膠 "glue / rubber / resin / vinyl" (膠水 = glue; 月 flesh radical). The black resin a record is pressed from.

## 凹痕 — ㄠ ㄏㄣˊ · (descriptive)

**意思 / meaning:** a groove / dent / indentation (here: the groove cut into a record).
**拆解 / breakdown:** 凹 "concave / sunken" (a pictograph of a notch — its shape *is* a dip; opposite of 凸 "convex") + 痕 "a mark / trace / scar" (痕跡 = trace; 疒 sickness radical). A sunken mark.
**記憶 / memory hook:** 凹 literally *looks* like a dent, and 凸 looks like a bump — a rare case where the character is the picture. 痕 adds "leftover mark".

## 監控 — ㄐㄧㄢ ㄎㄨㄥˋ · TOCFL 6

**意思 / meaning:** to monitor / surveil; surveillance (e.g. a security camera).
**拆解 / breakdown:** 監 "to supervise / watch over" (監督 = supervise; 監獄 = prison) + 控 "to control / keep in check" (控制). *Watch-and-control.*
**記憶 / memory hook:** 監 (oversee) + 控 (control) → keeping watch *and* keeping in check = surveillance. 監控攝像頭 = a security/CCTV camera.

## 噱頭 — ㄒㄩㄝˊ ㄊㄡˊ · C2

**意思 / meaning:** a gimmick; a hype stunt; a flashy hook with little substance.
**拆解 / breakdown:** 噱 "to laugh loudly / a funny act" (口 mouth radical) + 頭 "head" (here a colloquial noun suffix, as in 苗頭, 派頭). A "laugh-bit" — a showy attention-grabber.
**記憶 / memory hook:** Think of a salesperson's funny pitch (噱) — all show, no value. 只是噱頭 = "it's just a gimmick."
