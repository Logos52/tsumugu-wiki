# 2025 年度十大科技產品 — 詞彙編碼

## 黑膠 — ㄏㄟ ㄐㄧㄠ · C2

**意思 / meaning:** vinyl (records). Short for 黑膠唱片 — "black-rubber record".
**拆解 / breakdown:** 黑 "black" + 膠 "glue / rubber / resin / vinyl" (膠水 = glue; 月 flesh radical). The black resin a record is pressed from.
**記憶 / memory hook:** A vinyl LP is literally a disc of 黑 (black) 膠 (resin). 膠 also = 塑膠 (plastic), 口香糖 is 糖 not 膠 — but glue/gum is 膠.
**例句 / example:** 這臺小車是一個**黑膠**唱片機。

## 唱片 — ㄔㄤˋ ㄆㄧㄢˋ · B2

**意思 / meaning:** a record / LP / album.
**拆解 / breakdown:** 唱 "to sing" (唱歌) + 片 "a thin flat piece / disc / slice" (影片 = video; 照片 = photo). A flat disc that "sings."
**記憶 / memory hook:** 片 = any thin flat thing (照片 photo, 影片 video). The one that 唱 (sings) = a 唱片.
**例句 / example:** 小車會讀**唱片**上面的東西。

## 凹痕 — ㄠ ㄏㄣˊ · (descriptive)

**意思 / meaning:** a groove / dent / indentation (here: the groove cut into a record).
**拆解 / breakdown:** 凹 "concave / sunken" (a pictograph of a notch — its shape *is* a dip; opposite of 凸 "convex") + 痕 "a mark / trace / scar" (痕跡 = trace; 疒 sickness radical). A sunken mark.
**記憶 / memory hook:** 凹 literally *looks* like a dent, and 凸 looks like a bump — a rare case where the character is the picture. 痕 adds "leftover mark".
**例句 / example:** 它會讀唱片上的**凹痕**。

## 音質 — ㄧㄣ ㄓˋ · C2

**意思 / meaning:** sound quality; audio fidelity.
**拆解 / breakdown:** 音 "sound / tone" (聲音, 音樂) + 質 "quality / substance" (質量, 品質). The *quality of the sound.*
**記憶 / memory hook:** Parallel to 畫質 (image quality) and 品質 (quality): the 質 suffix = "-quality." 音質 = audio's 質.
**例句 / example:** 它很可愛，可是**音質**很差。

## 印表機 — ㄧㄣˋ ㄅㄧㄠˇ ㄐㄧ · (Tw)

**意思 / meaning:** a printer (the machine). Taiwan term; mainland 打印機.
**拆解 / breakdown:** 印 "to print / a seal / stamp" (印章, 蓋印) + 表 "form / table / surface" + 機 "machine". Originally a "form-printing machine."
**記憶 / memory hook:** 印 is the core (it's literally a chop/seal pressing ink). Tw 印表機 vs mainland 打印機 — both about 印 (printing). UV 印表機 = UV printer.
**例句 / example:** 這是世界上第一臺家用的 UV **印表機**。

## 列印 — ㄌㄧㄝˋ ㄧㄣˋ · C2 (Tw)

**意思 / meaning:** to print (out). Taiwan term; mainland 打印.
**拆解 / breakdown:** 列 "to line up / arrange / a row" (排列, 列表) + 印 "to print". Lay out in rows *and* print.
**記憶 / memory hook:** Pair the noun + verb: 印表機 (printer) does 列印 (printing). The 印 thread runs through both.
**例句 / example:** 它可以在木板上**列印**。

## 立體 — ㄌㄧˋ ㄊㄧˇ · TOCFL 6

**意思 / meaning:** three-dimensional; solid; stereoscopic (opposite of 平面, flat).
**拆解 / breakdown:** 立 "to stand / upright" + 體 "body / form". A form that *stands up* off the page = 3D.
**記憶 / memory hook:** 平面 (flat = level-surface) ↔ 立體 (3D = standing-body). If it 立 (stands up), it's 立體.
**例句 / example:** 它可以印出**立體**的東西。

## 精緻 — ㄐㄧㄥ ㄓˋ · (common)

**意思 / meaning:** exquisite; fine; delicately detailed and well-made.
**拆解 / breakdown:** 精 "refined / essence / fine" (精細, 精華) + 緻 "fine / delicate / dense" (糸 silk radical). Doubly "fine" — refined craftsmanship.
**記憶 / memory hook:** 精 (refined) you know from 精彩 (brilliant); 緻 adds the silk-thread fineness. 精緻 = "every tiny detail is right."
**例句 / example:** 印出來的東西非常**精緻**。

## 筆觸 — ㄅㄧˇ ㄔㄨˋ · TOCFL 7

**意思 / meaning:** a brushstroke; brushwork; an artist's "touch".
**拆解 / breakdown:** 筆 "pen / brush" (毛筆, 鉛筆) + 觸 "to touch / contact" (接觸). Where the *brush touches* — the mark it leaves.
**記憶 / memory hook:** 筆 (brush) + 觸 (touch) = the trace of brush-on-canvas. The UV printer even reproduces van Gogh's 筆觸.
**例句 / example:** 它連畫上的**筆觸**都能印出來。

## 掃描 — ㄙㄠˇ ㄇㄧㄠˊ · TOCFL 6

**意思 / meaning:** to scan (a document, a 3D object, a QR code).
**拆解 / breakdown:** 掃 "to sweep" (打掃 = clean/sweep; 扌 hand radical) + 描 "to trace / copy / depict" (描寫, 描繪; 扌 hand radical). *Sweep across and trace* it in.
**記憶 / memory hook:** Both halves have the 扌 hand radical — a hand sweeping (掃) and tracing (描) over the surface. A scanner "sweep-traces" an image.
**例句 / example:** 這些東西是用 3D **掃描**做出來的。

## 美甲 — ㄇㄟˇ ㄐㄧㄚˇ · C2

**意思 / meaning:** nail art; a manicure; (also) a fake/press-on nail set.
**拆解 / breakdown:** 美 "beautiful / to beautify" + 甲 "nail / shell / armor" (指甲 = fingernail; 甲 originally = shell/carapace). Beautifying the nails.
**記憶 / memory hook:** 指甲 = fingernail (finger-shell). Swap 指 → 美 = making the 甲 (nails) beautiful. 穿戴甲 = press-on nails.
**例句 / example:** 你也可以用它來做**美甲**。

## 降噪 — ㄐㄧㄤˋ ㄗㄠˋ · (audio term)

**意思 / meaning:** noise cancellation / noise reduction (ANC).
**拆解 / breakdown:** 降 "to lower / reduce" (read jiàng; 降低 = lower) + 噪 "noise / clamor" (噪音 = noise; 口 mouth radical ×3 vibe). *Lower the noise.*
**記憶 / memory hook:** 降 (lower) you know from 降價 (drop the price) — here it lowers 噪 (noise). 主動降噪 = active noise cancellation.
**例句 / example:** 它的**降噪**很好，能讓外面變安靜。

## 通透 — ㄊㄨㄥ ㄊㄡˋ · (descriptive)

**意思 / meaning:** clear and see-through; thoroughly penetrating; (headphones) transparency / ambient mode.
**拆解 / breakdown:** 通 "to pass through / connect / open" (通過) + 透 "to penetrate / transparent" (透明 = transparent). Doubly "lets-through" — nothing blocks it.
**記憶 / memory hook:** 透明 (transparent) + 通 (pass through) → sound (or light) passes cleanly through. In ANC headphones, 通透模式 lets the outside world in.
**例句 / example:** 它的**通透**很自然，戴著像沒戴一樣。

## 便攜 — ㄅㄧㄢˋ ㄒㄧㄝˊ · (tech term)

**意思 / meaning:** portable; portability; easy to carry.
**拆解 / breakdown:** 便 "convenient" (read biàn; 方便 = convenient) + 攜 "to carry / take along" (攜帶 = carry; 扌 hand radical). *Convenient to carry.*
**記憶 / memory hook:** 攜帶 = to carry along; 便攜 = "carry-convenient" = portable. Small gadget → high 便攜性.
**例句 / example:** 它很**便攜**，旅行的時候很好帶。

## 檢測儀 — ㄐㄧㄢˇ ㄘㄜˋ ㄧˊ · (tech term)

**意思 / meaning:** a tester / detector (measuring instrument).
**拆解 / breakdown:** 檢 "to inspect / check" (檢查) + 測 "to measure / test" (測量, 氵water radical) + 儀 "instrument" (儀器). An *inspect-and-measure instrument.* (儀 also in 陀螺儀.)
**記憶 / memory hook:** 檢 (check) + 測 (measure) + 儀 (-meter/instrument) = a "check-measure-meter." A cable 檢測儀 tests your USB-C cables.
**例句 / example:** 這個**檢測儀**可以告訴你線好不好。

## 標籤 — ㄅㄧㄠ ㄑㄧㄢ · (common)

**意思 / meaning:** a label / tag (physical or digital).
**拆解 / breakdown:** 標 "to mark / a marker" (標記, 目標) + 籤 "a slip / tag / label" (籤 originally a bamboo slip; 竹 bamboo radical, as in 書籤 = bookmark). A marking-slip.
**記憶 / memory hook:** 書籤 = bookmark (book-slip). 標籤 = a marking-slip you stick on things. 貼標籤 = to label / to stereotype.
**例句 / example:** 我幫所有的線都加上了**標籤**。

## 散熱 — ㄙㄢˋ ㄖㄜˋ · (tech term)

**意思 / meaning:** heat dissipation; cooling (getting heat out of a device).
**拆解 / breakdown:** 散 "to scatter / disperse" (read sàn; 解散 = disband) + 熱 "heat / hot" (熱). *Scatter the heat away.*
**記憶 / memory hook:** 散 (scatter) you know from 散步 (a stroll = scattered steps); here it scatters 熱 (heat). Good 散熱 = the gadget stays cool.
**例句 / example:** 它的**散熱**很好，不太會變熱。

## 監控 — ㄐㄧㄢ ㄎㄨㄥˋ · TOCFL 6

**意思 / meaning:** to monitor / surveil; surveillance (e.g. a security camera).
**拆解 / breakdown:** 監 "to supervise / watch over" (監督 = supervise; 監獄 = prison) + 控 "to control / keep in check" (控制). *Watch-and-control.*
**記憶 / memory hook:** 監 (oversee) + 控 (control) → keeping watch *and* keeping in check = surveillance. 監控攝像頭 = a security/CCTV camera.
**例句 / example:** 我在外面放了一個**監控**。

## 噱頭 — ㄒㄩㄝˊ ㄊㄡˊ · C2

**意思 / meaning:** a gimmick; a hype stunt; a flashy hook with little substance.
**拆解 / breakdown:** 噱 "to laugh loudly / a funny act" (口 mouth radical) + 頭 "head" (here a colloquial noun suffix, as in 苗頭, 派頭). A "laugh-bit" — a showy attention-grabber.
**記憶 / memory hook:** Think of a salesperson's funny pitch (噱) — all show, no value. 只是噱頭 = "it's just a gimmick."
**例句 / example:** 希望明年有更多不只是**噱頭**的東西。
