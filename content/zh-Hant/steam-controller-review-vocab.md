## 硬體 — ㄧㄥˋ ㄊㄧˇ · TOCFL 5

**意思 / meaning:** hardware (the physical kit). Taiwan term; mainland says 硬件.
**拆解 / breakdown:** 硬 "hard" + 體 "body / substance". The *hard body* of a system — opposite of 軟體 (software, "soft body").
**記憶 / memory hook:** Learn the pair together: 硬體 (hardware) ↔ 軟體 (software), literally hard-body vs soft-body. 韌體 (firmware, below) is the *tough* in-between.
**例句 / example:** Steam 也做自己的**硬體**了。

## 手柄 — ㄕㄡˇ ㄅㄧㄥˇ · C2

**意思 / meaning:** a game controller / gamepad; also a "handle" in general.
**拆解 / breakdown:** 手 "hand" + 柄 "handle / grip (of a tool)". The thing your hand grips. 柄 also appears in 話柄 (a handle for gossip) — something to grab onto.
**記憶 / memory hook:** Literally a "hand-handle". The PS5/Xbox thing you hold = 手柄.
**例句 / example:** 這個 Steam **手柄**要 700 塊。

## 口碑 — ㄎㄡˇ ㄅㄟ · TOCFL 6

**意思 / meaning:** reputation by word-of-mouth; what people say about a product/person.
**拆解 / breakdown:** 口 "mouth" + 碑 "a stone monument / stele" (石 stone radical). A "monument built of mouths" — a reputation carved by everyone's talk.
**記憶 / memory hook:** Imagine a stone tablet (碑) inscribed not with words but with everyone's *mouths* (口) — your public rep. 好口碑 = good word-of-mouth.
**例句 / example:** Steam 的**口碑**一直很好。

## 對稱 — ㄉㄨㄟˋ ㄔㄥˋ · TOCFL 6

**意思 / meaning:** symmetrical; symmetry.
**拆解 / breakdown:** 對 "to match / pair / facing" + 稱 "to weigh / balance / match" (here read chèng). Matched-and-balanced = symmetrical. (對稱佈局 = symmetric layout.)
**記憶 / memory hook:** 對 = a matched pair facing each other; if both sides also *balance* (稱), it's 對稱. The sticks sit left-right 對稱.
**例句 / example:** 它左右兩邊長得很**對稱**。

## 觸控板 — ㄔㄨˋ ㄎㄨㄥˋ ㄅㄢˇ · (Tw tech term)

**意思 / meaning:** touchpad / trackpad.
**拆解 / breakdown:** 觸 "to touch / contact" (接觸, 觸覺) + 控 "to control" (控制) + 板 "board / panel" (木 wood radical). A *touch-control board.*
**記憶 / memory hook:** 觸 (touch) + 控 (control) + 板 (panel) reads almost like English "touch-control-pad". The Steam Deck's signature feature.
**例句 / example:** 它有兩塊**觸控板**，用手碰就能用。

## 搖桿 — ㄧㄠˊ ㄍㄢˇ · (gaming term)

**意思 / meaning:** joystick; analog thumbstick.
**拆解 / breakdown:** 搖 "to shake / wave / wobble" (搖頭 = shake head) + 桿 "rod / pole / stick" (木 wood radical; 球桿 = golf club). A *wobble-stick.*
**記憶 / memory hook:** 搖 (wiggle) + 桿 (rod) → the little rod you wiggle with your thumb. 漂移 (below) is when it wiggles by itself.
**例句 / example:** 它的**搖桿**幾乎不會自己動。

## 漂移 — ㄆㄧㄠ ㄧˊ · C2

**意思 / meaning:** to drift; (controllers) stick-drift — phantom input when the stick isn't touched. Also car "drifting".
**拆解 / breakdown:** 漂 "to float / drift on water" (氵water radical) + 移 "to move / shift" (禾 grain radical). Float-and-shift = drift away from where it should be.
**記憶 / memory hook:** 漂 has water (氵) — like something floating off downstream. A drifting joystick "floats" off-center on its own.
**例句 / example:** 它幾乎不會**漂移**。

## 續航 — ㄒㄩˋ ㄏㄤˊ · (tech term)

**意思 / meaning:** battery life / runtime (lit. "continued voyage" — how long it runs before recharging).
**拆解 / breakdown:** 續 "to continue / extend" (繼續 = continue; 糸 silk radical = an unbroken thread) + 航 "to sail / voyage / fly" (航行, 航空). Keep *sailing* without refuelling.
**記憶 / memory hook:** From ships and planes — how far it can 航 (voyage) without stopping. Now means how long your gadget lasts on a charge.
**例句 / example:** 它的**續航**很久，可以玩很長時間。

## 相容 — ㄒㄧㄤ ㄖㄨㄥˊ · TOCFL 6

**意思 / meaning:** compatible; to be mutually tolerant. 相容性 = compatibility.
**拆解 / breakdown:** 相 "mutually / each other" (互相) + 容 "to contain / hold / tolerate" (容納, 包容). Mutually able to *hold* each other = compatible.
**記憶 / memory hook:** 容 = to make room for; 相容 = two systems making room for each other. The 性 suffix turns it into the noun "-ity" (相容性 = compatibility).
**例句 / example:** 它的**相容**很好，可是只能用在 Steam 上。

## 韌體 — ㄖㄣˋ ㄊㄧˇ · (Tw tech term)

**意思 / meaning:** firmware (the low-level software baked into hardware).
**拆解 / breakdown:** 韌 "tough / tenacious / pliable-but-strong" (堅韌) + 體 "body". The "tough-body" layer — sits between 硬體 (hardware) and 軟體 (software).
**記憶 / memory hook:** Complete the trio: 硬體 hard / 軟體 soft / **韌體 tough** = hardware / software / *firm*ware. The English "firm" ≈ 韌 (firm, tough).
**例句 / example:** Steam 可以幫它換新的**韌體**。

## 陀螺儀 — ㄊㄨㄛˊ ㄌㄨㄛˊ ㄧˊ · (tech term)

**意思 / meaning:** gyroscope (motion sensor used for tilt-aiming).
**拆解 / breakdown:** 陀螺 "a spinning top (toy)" + 儀 "instrument / apparatus" (儀器). A "spinning-top instrument" — it senses rotation. (儀 also in 檢測儀, 儀式.)
**記憶 / memory hook:** A gyroscope *is* basically a precision spinning top — Chinese names it exactly that: 陀螺 (top) + 儀 (instrument).
**例句 / example:** 你可以用**陀螺儀**來玩遊戲。

## 瞄準 — ㄇㄧㄠˊ ㄓㄨㄣˇ · TOCFL 7

**意思 / meaning:** to aim (at); to target.
**拆解 / breakdown:** 瞄 "to fix one's eye on / take aim" (目 eye radical) + 準 "accurate / on-target" (準確). Eye-on-target *accurately* = aim.
**記憶 / memory hook:** 瞄 has the 目 (eye) radical — you *eye* the target; 準 makes it precise. Also 瞄準目標 = target an audience (figurative).
**例句 / example:** 用它可以**瞄準**得更好。

## 延遲 — ㄧㄢˊ ㄔˊ · TOCFL 6

**意思 / meaning:** delay; (computing) latency / lag.
**拆解 / breakdown:** 延 "to extend / prolong / stretch out (time)" + 遲 "late / slow" (遲到 = arrive late). Stretched-out lateness = a delay.
**記憶 / memory hook:** You know 遲到 (be late). 延遲 = the lateness *introduced* into a signal. Low 延遲 = snappy input.
**例句 / example:** 它的**延遲**很低，用起來很快。

## 喚醒 — ㄏㄨㄢˋ ㄒㄧㄥˇ · TOCFL 6

**意思 / meaning:** to wake (someone/something) up; (tech) to wake a device from sleep.
**拆解 / breakdown:** 喚 "to call / summon" (口 mouth radical; 呼喚 = call out) + 醒 "to wake / be awake" (酉 wine radical — sobering up; 醒來). *Call something awake.*
**記憶 / memory hook:** 醒 (wake) you may know from 睡醒 (wake from sleep). 喚 (call) + 醒 = call-it-awake. You 喚醒 the PC from the couch.
**例句 / example:** 你可以坐在家裡**喚醒**電腦。

## 即插即用 — ㄐㄧˊ ㄔㄚ ㄐㄧˊ ㄩㄥˋ · (tech idiom)

**意思 / meaning:** plug-and-play — works the instant you plug it in, no setup.
**拆解 / breakdown:** A neat 4-char calque: 即 "immediately / as soon as" + 插 "to plug / insert" + 即 "immediately" + 用 "use". *Plug → immediately use.*
**記憶 / memory hook:** The 即…即… frame = "as soon as A, then B": 即插即用 = "the moment you plug, you use." Same frame as 即興 (improvise = as-the-mood-arises).
**例句 / example:** 它差不多做到了**即插即用**。

## 自定義 — ㄗˋ ㄉㄧㄥˋ ㄧˋ · (tech term)

**意思 / meaning:** to customize; custom / user-defined.
**拆解 / breakdown:** 自 "self" + 定義 "definition / to define" (定 fix + 義 meaning). *Self-defined.*
**記憶 / memory hook:** You half-know 定義 (definition); just prefix 自 (self) → you set the definition yourself. The Steam handle's whole appeal is 高度自定義.
**例句 / example:** 它的**自定義**很多，可以改成你要的樣子。

## 價效比 — ㄐㄧㄚˋ ㄒㄧㄠˋ ㄅㄧˇ · (Tw consumer term)

**意思 / meaning:** value for money; price-to-performance ratio (Tw; mainland 性價比).
**拆解 / breakdown:** 價 "price" (價格) + 效 "effect / performance" (效果, 效能) + 比 "ratio / to compare". The *price-vs-performance ratio.*
**記憶 / memory hook:** Tw flips the mainland 性價比 to 價效比 — but both mean "bang for your buck": 價 (price) ÷ 效 (performance). High 價效比 = great deal.
**例句 / example:** 700 塊的**價效比**剛剛好。

## 碾壓 — ㄋㄧㄢˇ ㄧㄚ · (colloquial)

**意思 / meaning:** to crush / steamroll; (fig.) to utterly outperform, "wipe the floor with".
**拆解 / breakdown:** 碾 "to roll / grind (with a stone roller)" (石 stone radical) + 壓 "to press down / crush". Roll-and-crush. Picture a road roller flattening the competition.
**記憶 / memory hook:** Both halves are about heavy downward force (石 stone + 壓 press). In reviews, A 碾壓 B = A totally dominates B.
**例句 / example:** 它還沒有完全**碾壓**別的工具。
