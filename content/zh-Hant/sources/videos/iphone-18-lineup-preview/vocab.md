## 折疊屏 — ㄓㄜˊ ㄉㄧㄝˊ ㄆㄧㄥˊ · (tech term)

**意思 / meaning:** foldable screen; the foldable-phone category.
**拆解 / breakdown:** 折 "to fold" + 疊 "to stack" (重疊 overlap) + 屏 "screen". Fold-stack-screen.
**記憶 / memory hook:** Folding *stacks* the screen onto itself: 折 + 疊. Add 屏 and you have the whole category — 折疊屏手機.
**例句 / example:** 今年 Apple 要出第一支**折疊屏** iPhone 了。

## 機模 — ㄐㄧ ㄇㄛˊ · (industry term)

**意思 / meaning:** dummy unit / mockup — a non-working model of a phone.
**拆解 / breakdown:** 機 "machine, phone" (手機) + 模 "model, mold" (模型). A phone-model.
**記憶 / memory hook:** 手機的模型, shortened to 機模. Case makers build cases on 機模 before launch — that's why leaks have one.
**例句 / example:** 影片裡的不是真手機，是一個**機模**。

## 曝光 — ㄆㄨˋ ㄍㄨㄤ · TOCFL 6

**意思 / meaning:** to be exposed / leaked (news, products); (photography) exposure.
**拆解 / breakdown:** 曝 "to expose to the sun" (日 sun radical) + 光 "light". Put under the light.
**記憶 / memory hook:** A leak drags secrets into sunlight. Phone reviews use it both ways: specs 曝光 (leaked) and photos need the right 曝光 (exposure).
**例句 / example:** 新手機還沒出，就已經全部**曝光**了。

## 漲價 — ㄓㄤˇ ㄐㄧㄚˋ · TOCFL 5

**意思 / meaning:** to go up in price.
**拆解 / breakdown:** 漲 "to rise (like water)" (氵 water radical) + 價 "price" (價錢). Prices rising like floodwater.
**記憶 / memory hook:** 漲 is rising water — in 2026 everything 漲價, prices flooding upward. The video calls it 瘋狂漲價的年代.
**例句 / example:** 這幾年什麼都在**漲價**。

## 供應鏈 — ㄍㄨㄥ ㄧㄥˋ ㄌㄧㄢˋ · (business term)

**意思 / meaning:** supply chain.
**拆解 / breakdown:** 供應 "to supply" (供 provide + 應 answer a need) + 鏈 "chain" (金 metal radical, 鎖鏈).
**記憶 / memory hook:** 鏈 = a chain of metal links — factories linked hand to hand. Apple delayed the 18 so the 供應鏈 could feed Ultra first.
**例句 / example:** 因為**供應鏈**做不出那麼多，普通的 18 要等明年。

## 產能 — ㄔㄢˇ ㄋㄥˊ · (business term)

**意思 / meaning:** production capacity.
**拆解 / breakdown:** 產 "to produce" (生產) + 能 "capacity" (能力). Produce-ability — short for 生產能力.
**記憶 / memory hook:** When reviewers say 產能不夠, it means: they can't make enough units — so buy on day one or wait months.
**例句 / example:** 新東西太難做，**產能**一定不夠。

## 晶片 — ㄐㄧㄥ ㄆㄧㄢˋ · TOCFL 7

**意思 / meaning:** chip / semiconductor (Tw term; mainland says 芯片).
**拆解 / breakdown:** 晶 "crystal" (three suns — sparkling; 水晶) + 片 "slice, thin piece". A crystal slice.
**記憶 / memory hook:** A chip literally *is* a thin slice cut from a silicon crystal: 晶 + 片. The A20 is this year's headline 晶片.
**例句 / example:** 今年的**晶片**更快，也更省電。

## 製程 — ㄓˋ ㄔㄥˊ · (semiconductor term)

**意思 / meaning:** manufacturing process; (chips) the process node — "2 奈米".
**拆解 / breakdown:** 製 "to make, manufacture" (製造) + 程 "process, procedure" (過程). The making-process.
**記憶 / memory hook:** Every chip launch leads with its 製程 ("2nm process") — the finer the 製程, the faster and cooler the 晶片.
**例句 / example:** 新的**製程**讓手機更快、也更省電。

## 折痕 — ㄓㄜˊ ㄏㄣˊ · (tech term)

**意思 / meaning:** crease — the fold mark on a foldable's screen.
**拆解 / breakdown:** 折 "fold" + 痕 "mark, scar" (傷痕 a scar). The fold-scar.
**記憶 / memory hook:** 痕 = scar: a foldable's screen carries the scar of its folding. Apple's claim: almost no 折痕 at all.
**例句 / example:** 它的畫面幾乎看不到**折痕**。

## 鉸鏈 — ㄐㄧㄠˇ ㄌㄧㄢˋ · (hardware term)

**意思 / meaning:** hinge.
**拆解 / breakdown:** 鉸 "hinged joint" + 鏈 "chain" — both carry the metal radical 金. The moving metal joint.
**記憶 / memory hook:** Same 鏈 as 供應鏈. A door swings on its 鉸鏈; a foldable lives or dies by its 鉸鏈 — Apple's uses liquid metal.
**例句 / example:** 打開、關起來好不好用，就看**鉸鏈**做得好不好。

## 妥協 — ㄊㄨㄛˇ ㄒㄧㄝˊ · TOCFL 6

**意思 / meaning:** to compromise; a compromise / trade-off.
**拆解 / breakdown:** 妥 "settled, proper" (妥當) + 協 "to join forces" (協助 — 十 plus three 力, many strengths together). Settling by meeting halfway.
**記憶 / memory hook:** In reviews 妥協 = trade-off. The Ultra's list: no Face ID, two cameras, maybe no MagSafe — 每一個都是妥協.
**例句 / example:** 做得這麼特別的手機，一定會有**妥協**。

## 長焦 — ㄔㄤˊ ㄐㄧㄠ · (camera term)

**意思 / meaning:** telephoto (lens); long focal length.
**拆解 / breakdown:** 長 "long" + 焦 "focus, focal" (焦點 focal point; 灬 fire — where the lens burns light to a point).
**記憶 / memory hook:** 焦 is where light *burns* to a point — the focal point. 長焦 = long-focus glass that pulls far things near. Ultra 沒有長焦.
**例句 / example:** Ultra 沒有**長焦**，Pro Max 有。

## 光圈 — ㄍㄨㄤ ㄑㄩㄢ · (camera term)

**意思 / meaning:** aperture — the opening that lets light into a lens.
**拆解 / breakdown:** 光 "light" + 圈 "circle, ring" (圓圈). The light-circle.
**記憶 / memory hook:** Literally the circle light passes through. This year's Pro headline: 可調光圈 — an aperture you can open and close.
**例句 / example:** **光圈**可以變大變小，晚上拍照更好看。

## 辨識度 — ㄅㄧㄢˋ ㄕˋ ㄉㄨˋ · (design term)

**意思 / meaning:** recognizability — how instantly identifiable something looks.
**拆解 / breakdown:** 辨識 "to recognize" (辨 distinguish + 識 know) + 度 "degree". Degree-of-being-recognized.
**記憶 / memory hook:** The 度 suffix again: 透明度, 辨識度. High 辨識度 = everyone across the room knows you're holding the new one — the Ultra's real selling point.
**例句 / example:** 大家一看就知道是新 iPhone，這就是**辨識度**。

## 輕奢 — ㄑㄧㄥ ㄕㄜ · (consumer term)

**意思 / meaning:** "light luxury" / affordable luxury — premium but just within reach.
**拆解 / breakdown:** 輕 "light(weight)" + 奢 "extravagant" (奢侈). Luxury, but the light kind.
**記憶 / memory hook:** Between everyday goods and true luxury sits 輕奢 — an LV-priced phone. The video: iPhone 重回輕奢地位.
**例句 / example:** 18000 塊的手機，已經是**輕奢**了。

## 塵埃落定 — ㄔㄣˊ ㄞ ㄌㄨㄛˋ ㄉㄧㄥˋ · (idiom)

**意思 / meaning:** the dust has settled — everything is decided / confirmed.
**拆解 / breakdown:** 塵埃 "dust" (塵 = 鹿 deer over 土 earth — dust kicked up by running deer; 埃 fine dust) + 落定 "fall and settle".
**記憶 / memory hook:** After the stampede, the dust falls and you finally see what happened. Four months before launch, every spec 已經塵埃落定.
**例句 / example:** 新 iPhone 長什麼樣子，已經**塵埃落定**。
