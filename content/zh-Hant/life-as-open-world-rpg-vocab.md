## 穿戴 — ㄔㄨㄢ ㄉㄞˋ · TOCFL 5

**意思 / meaning:** to wear on the body; (as 穿戴裝置) a *wearable* device.
**拆解 / breakdown:** 穿 "to wear (clothes), to put on" + 戴 "to wear (accessories: hat, glasses, watch)". The pair covers *everything* you put on your body — Chinese splits "wear" into 穿 (things you step/slip into) vs 戴 (things you hang/strap on). A neck gadget is 戴.
**記憶 / memory hook:** 穿 has 穴 (a cave/hole) on top — you pass *through* a hole into clothes. 戴 you already know from 戴眼鏡 (wear glasses).
**例句 / example:** 這個工具可以**穿戴**在身上。

## 新奇 — ㄒㄧㄣ ㄑㄧˊ · TOCFL 5

**意思 / meaning:** novel; fresh and unusual; a "wow, never seen that" feeling.
**拆解 / breakdown:** 新 "new" + 奇 "strange / rare". New *and* odd = striking, curiosity-grabbing. Different from plain 新 (just recent).
**記憶 / memory hook:** 奇 also lives in 奇怪 (strange) and 好奇 (curious) — 新奇 is the *good* kind of strange.
**例句 / example:** 第一次用，覺得很**新奇**。

## 視角 — ㄕˋ ㄐㄧㄠˇ · TOCFL 6

**意思 / meaning:** perspective; point of view; camera angle (literal *and* figurative).
**拆解 / breakdown:** 視 "to look / vision" (as in 電視, 視力) + 角 "angle / corner" (as in 角度, 三角). The *angle of looking* = viewpoint. 第一視角 = first-person view.
**記憶 / memory hook:** 角 is a pictograph of a horn — a sharp angle. Pair it with 視 (looking) → the angle you look from.
**例句 / example:** 它用你的**視角**把東西拍下來。

## 磁吸 — ㄘˊ ㄒㄧ · (above TOCFL list — tech term)

**意思 / meaning:** to attach magnetically; magnetic mount/snap-on.
**拆解 / breakdown:** 磁 "magnetic / magnet" (磁鐵 = magnet) + 吸 "to suck / draw in" (呼吸 = breathe; 吸引 = attract). A magnet that *pulls* things to it = snaps on.
**記憶 / memory hook:** 吸 has 口 (mouth) on the left — sucking *in* through a mouth. The magnet "sucks" the device onto the dock.
**例句 / example:** 它可以**磁吸**在充電的地方。

## 素材 — ㄙㄨˋ ㄘㄞˊ · TOCFL 6

**意思 / meaning:** source material; raw footage / ingredients for making something.
**拆解 / breakdown:** 素 "plain / raw / element" (元素 = element) + 材 "material / timber" (材料 = material; 木 wood radical). Raw stuff you'll later shape — clips, photos, notes.
**記憶 / memory hook:** A creator's 素材 is their "raw lumber" (材 has the 木 wood radical) before editing.
**例句 / example:** 它把這些**素材**交給 AI。

## 生成 — ㄕㄥ ㄔㄥˊ · TOCFL 6

**意思 / meaning:** to generate / produce (now the standard word for AI *generation*).
**拆解 / breakdown:** 生 "to give birth / produce" + 成 "to become / complete". Bring into being *and* finish it = generate a finished thing. 生成式 AI = generative AI.
**記憶 / memory hook:** 生 (birth) + 成 (becomes) → something is *born into* a completed form. This is *the* word for AI output.
**例句 / example:** AI 會自己**生成**一支小影片。

## 識別 — ㄕˊ ㄅㄧㄝˊ · TOCFL 6

**意思 / meaning:** to recognize; to identify; to tell apart.
**拆解 / breakdown:** 識 "to know / recognize" (認識 = be acquainted; 知識 = knowledge) + 別 "to distinguish / separate" (分別 = differentiate). Knowing *and* telling apart = identify.
**記憶 / memory hook:** You already know 認識 (to know a person). Swap 認 → just 識 + 別 (separate) = the machine "knows-and-separates" what it sees.
**例句 / example:** 它會自己**識別**你在做什麼。

## 情境 — ㄑㄧㄥˊ ㄐㄧㄥˋ · TOCFL 6

**意思 / meaning:** situation; context; the scene/circumstances you're in.
**拆解 / breakdown:** 情 "feeling / circumstance" (情況, 心情) + 境 "boundary / environment / state" (環境, 邊境). The *felt environment* = the context.
**記憶 / memory hook:** 境 shares 竟/章 phonetic and means "a bounded place"; 情境 = the emotional *place* you're in. Compare 環境 (physical environment) → 情境 (situational environment).
**例句 / example:** 它知道你現在在什麼**情境**。

## 自定義 — ㄗˋ ㄉㄧㄥˋ ㄧˋ · (tech term)

**意思 / meaning:** to customize; custom / user-defined.
**拆解 / breakdown:** 自 "self" + 定 "to fix / set" + 義 "meaning / definition". *Self-set definition* = you define it yourself. Same shape as English "self-define".
**記憶 / memory hook:** 自定義 = 自 (self) + 定義 (definition). You already half-know 定義 (definition) — just put 自 in front.
**例句 / example:** 你可以**自定義**它要做的事。

## 探索 — ㄊㄢˋ ㄙㄨㄛˇ · TOCFL 6

**意思 / meaning:** to explore; to probe / seek out.
**拆解 / breakdown:** 探 "to probe / reach in for" (探險 = adventure; 手 hand radical) + 索 "to search / a rope". Reach in *and* search = explore.
**記憶 / memory hook:** 探 has the 扌 hand radical — you *reach a hand in* to explore the unknown. Think 探險 (adventure).
**例句 / example:** 像玩遊戲一樣去**探索**生活。

## 專注 — ㄓㄨㄢ ㄓㄨˋ · TOCFL 5

**意思 / meaning:** to concentrate; focused attention (on one thing).
**拆解 / breakdown:** 專 "single / exclusive / specialized" (專門, 專業) + 注 "to pour / focus" (注意 = pay attention; 氵water radical). *Pour all of yourself into one thing.*
**記憶 / memory hook:** 注 (pour, water radical) + 專 (only one) → pour your whole mind into a *single* spot. Cousin of 注意 (notice).
**例句 / example:** 它提醒你回去**專注**做事。

## 外掛 — ㄨㄞˋ ㄍㄨㄚˋ · (gaming / tech slang)

**意思 / meaning:** a plug-in / add-on; (gaming slang) a cheat / external mod. Here: an "external brain" bolted on.
**拆解 / breakdown:** 外 "outside / external" + 掛 "to hang / hook on" (掛電話 = hang up). *Hooked on from the outside* = an add-on module.
**記憶 / memory hook:** Picture something *hung on the outside* of your system — 外 (outside) + 掛 (hang). In games it means an illegal helper; here, a helpful one.
**例句 / example:** 它就像一個**外掛**，幫你記住每天的事。

## 觀察 — ㄍㄨㄢ ㄔㄚˊ · TOCFL 5

**意思 / meaning:** to observe; to watch closely and study.
**拆解 / breakdown:** 觀 "to view / contemplate" (參觀 = visit/tour; 觀點 = viewpoint) + 察 "to examine / inspect" (檢察, 警察). View *plus* inspect = observe attentively.
**記憶 / memory hook:** 觀 (big-picture viewing) + 察 (close inspection) → seeing both wide and deep. The device 觀察s your day so you don't have to.
**例句 / example:** 它會慢慢**觀察**你的一天。

## 平凡 — ㄆㄧㄥˊ ㄈㄢˊ · TOCFL 5

**意思 / meaning:** ordinary; commonplace; nothing special.
**拆解 / breakdown:** 平 "flat / level / ordinary" (平常, 公平) + 凡 "mortal / common / every". Flat-and-common = unremarkable. Opposite of 特別 / 精彩.
**記憶 / memory hook:** 凡 alone means "the mundane world" (vs. 仙 immortals). 平凡 = life at ground level, no peaks.
**例句 / example:** 連最**平凡**的一天，它也留下來。

## 覆盤 — ㄈㄨˋ ㄆㄢˊ · (chess/business term)

**意思 / meaning:** to review / replay (originally: replaying a finished chess game move-by-move to learn from it); a retrospective.
**拆解 / breakdown:** 覆 "to overturn / repeat / cover again" + 盤 "board / tray (the chess board, 棋盤)". Re-lay the *board* = replay the whole game to study it.
**記憶 / memory hook:** From 圍棋/象棋: after the match you *re-set the board* (覆盤) to see where you went wrong. Now used for any after-action review.
**例句 / example:** 每天晚上**覆盤**一下，看看自己過得好不好。

## 思緒 — ㄙ ㄒㄩˋ · TOCFL 6

**意思 / meaning:** train of thought; the threads of one's thinking/mood.
**拆解 / breakdown:** 思 "to think" (思考, 意思) + 緒 "thread / strand-ends" (糸 silk radical; 頭緒 = a lead/clue; 情緒 = emotions). *Threads of thought.*
**記憶 / memory hook:** 緒 has the 糸 silk radical — thoughts as loose *threads* you tidy up. Sister word: 情緒 (emotion-threads). 整理思緒 = sort out your thinking.
**例句 / example:** 寫東西可以讓你的**思緒**清楚一點。

## 疏導 — ㄕㄨ ㄉㄠˇ · TOCFL 6

**意思 / meaning:** to channel / ease / let out (emotions, traffic, water) by guiding it, not blocking it.
**拆解 / breakdown:** 疏 "to dredge / unblock / sparse" + 導 "to guide / lead" (導師, 引導). Clear the channel *and* guide the flow — relieve a build-up by directing it.
**記憶 / memory hook:** Originally water engineering (dredge 疏 + lead 導 a river so it won't flood). Apply it to feelings: 疏導情緒 = let emotions flow out instead of damming them up.
**例句 / example:** 把難過寫下來，是一種**疏導**。

## 畫面 — ㄏㄨㄚˋ ㄇㄧㄢˋ · TOCFL 4

**意思 / meaning:** the image / picture on a screen; a visual scene or frame.
**拆解 / breakdown:** 畫 "to draw / a picture" (畫畫, 圖畫) + 面 "surface / face". The *picture surface* = what's shown on screen, or a mental "scene".
**記憶 / memory hook:** 面 = surface/face (e.g. 表面). 畫面 = the "picture-face" you see — a single visual moment. A feeling can't be captured as a mere 畫面.
**例句 / example:** 心裡的感覺，很難只用**畫面**留下來。
