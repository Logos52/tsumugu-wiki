## 開發者 — ㄎㄞ ㄈㄚ ㄓㄜˇ · (tech term)

**意思 / meaning:** developer — the people who write the apps. WWDC = 開發者大會.
**拆解 / breakdown:** 開發 "to develop / open up" (開 open + 發 send forth) + 者 "-er, one who does".
**記憶 / memory hook:** 者 turns a verb into a person, exactly like 作者 (writer) and 記者 (reporter) — 開發者 = the *develop-er*.
**例句 / example:** Apple 的大會是開給**開發者**看的。

## 助理 — ㄓㄨˋ ㄌㄧˇ · TOCFL 5

**意思 / meaning:** assistant (person or role); the new Siri's whole positioning.
**拆解 / breakdown:** 助 "to help" (幫助) + 理 "to manage / put in order" (整理). A help-manager.
**記憶 / memory hook:** You know 幫助 and 整理 — an assistant helps you keep things in order: 助＋理. AI 助理 is the 2026 phrase to own.
**例句 / example:** 新的 Siri 像一個會幫你做事的**助理**。

## 穩定性 — ㄨㄣˇ ㄉㄧㄥˋ ㄒㄧㄥˋ · (tech term)

**意思 / meaning:** stability (of a system).
**拆解 / breakdown:** 穩 "steady" + 定 "fixed, settled" (一定) + 性 the "-ness/-ity" suffix.
**記憶 / memory hook:** 性 is the noun-maker you saw in 相容性 (compatibility): 穩定 stable → 穩定性 stability. This year's iOS is *about* 穩定性.
**例句 / example:** iOS 27 的**穩定性**，比 26 好了很多。

## 透明度 — ㄊㄡˋ ㄇㄧㄥˊ ㄉㄨˋ · (tech term)

**意思 / meaning:** transparency — how see-through something is (also fig., of organizations).
**拆解 / breakdown:** 透 "to pass through" + 明 "bright" + 度 "degree". The degree of light passing through.
**記憶 / memory hook:** 度 measures: 速度 (speed), 透明度 (transparency), 辨識度 (recognizability). iOS 27's new slider literally adjusts 透明度.
**例句 / example:** 你可以讓 Liquid Glass 的**透明度**變高或變低。

## 液態玻璃 — ㄧㄝˋ ㄊㄞˋ ㄅㄛ ㄌㄧˊ · (Apple term)

**意思 / meaning:** "Liquid Glass", Apple's design language since iOS 26.
**拆解 / breakdown:** 液 "liquid" (氵 water radical) + 態 "state, form" (狀態) + 玻璃 "glass". Liquid-state glass.
**記憶 / memory hook:** 態 = state: 液態 liquid-state, 固態 solid-state (SSD = 固態硬碟), 形態 form. Glass in its liquid state = the flowing UI.
**例句 / example:** 有人愛**液態玻璃**，有人不愛。

## 鬧鐘 — ㄋㄠˋ ㄓㄨㄥ · TOCFL 3

**意思 / meaning:** alarm clock.
**拆解 / breakdown:** 鬧 "noisy, to make a racket" (熱鬧) + 鐘 "clock, bell". The noisy clock.
**記憶 / memory hook:** Same 鬧 as 熱鬧 (lively) — the clock that makes a racket at you. iOS 27's quietly epic fix: 鬧鐘 now respects shifted rest days.
**例句 / example:** 我每天早上都要**鬧鐘**叫我起來。
