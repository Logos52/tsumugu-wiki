# Wiki reading vocab — Serena audio + A/B-loop waveforms

Vocab encoder pages (`type: vocab` in frontmatter) carry voiced 例句 blocks
generated by `scripts/wiki_vocab_audio.py`. Each Chinese example sentence gets:

- a pre-baked **Serena** (Qwen3-TTS) clip under `content/zh-Hant/audio/vocab/<slug>/`
- transcribe-back QA (whisper) per PRD-Entry-Authoring / dict-demo contract
- an inline **🌊 A/B-loop** waveform (wavesurfer.js v7, same as the Encoding Dictionary demo)

## Pipeline

```sh
python3 scripts/wiki_vocab_audio.py all              # full pass on all readings
python3 scripts/wiki_vocab_audio.py all --slug ios27-epic-update
python3 scripts/wiki_vocab_audio.py audit          # re-check only
```

Requires the Tsumugu voice venv (`mlx_audio`, `mlx_whisper`, `opencc`, `ffmpeg`).
